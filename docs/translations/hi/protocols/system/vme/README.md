# VME / VPX प्रोटोकॉल SDK

Linux procfs के माध्यम से VMEbus और VPX बस एक्सेस के लिए `kernel.Protocol` लागू करता है।

## प्रोटोकॉल

- **नाम**: `vme`
- **वेरिएंट**: `vme`
- **डिफ़ॉल्ट पोर्ट**: 0 (मेमोरी-मैप्ड बस)
- **ट्रांसपोर्ट**: procfs `/proc/vme/<slot>`

कोडेक एप्लिकेशन और VME एड्रेस स्पेस के बीच कच्चे बाइट्स को पारित
करता है। रीड और राइट VME कर्नेल ड्राइवर द्वारा प्रदान किए गए procfs
इंटरफ़ेस के माध्यम से सीधे बस तक जाते हैं।

## कर्नेल आवश्यकताएँ

निम्नलिखित कर्नेल मॉड्यूल लोड होना चाहिए:

- `vme_tsi148` -- Tundra TSI148 VME ब्रिज ड्राइवर (सबसे सामान्य)
  - समर्थित भी: `vme_ca91cx42` (Universe II), `vme_user`

procfs फाइलसिस्टम `/proc` पर माउंट होना चाहिए।

आवश्यक अनुमतियाँ:
- `/proc/vme/<slot>` को रीड-राइट के लिए खोलने हेतु रूट एक्सेस आवश्यक है
- डिवाइस नोड root:root के स्वामित्व में हैं

## ड्राइवर

```go
d, err := vme.NewVMEDriver(0) // slot 0
if err != nil {
    log.Fatal(err)
}
defer d.Close()

tr := d.Transport()
// Use tr.Read/tr.Write for raw VME bus access
```

## VME एड्रेसिंग मोड

कोडेक सभी एड्रेस मॉडिफायर और एड्रेस बाइट्स को पारदर्शी रूप से पारित
करता है। एप्लिकेशन को डेटा पेलोड में एड्रेसिंग जानकारी जोड़नी चाहिए:

- **A16**: 16-बिट शॉर्ट I/O एड्रेस स्पेस
- **A24**: 24-बिट मानक एड्रेस स्पेस
- **A32**: 32-बिट विस्तारित एड्रेस स्पेस

## VPX संगतता

VME-संगत procfs इंटरफ़ेस उजागर करने वाले VPX (VITA 46) सिस्टम
इस ड्राइवर का उपयोग कर सकते हैं। स्लॉट नंबरिंग समान है।
