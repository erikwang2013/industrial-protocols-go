# CompactPCI प्रोटोकॉल SDK

Linux sysfs के माध्यम से CompactPCI बस एक्सेस के लिए `kernel.Protocol` लागू करता है।

## प्रोटोकॉल

- **नाम**: `cpci`
- **वेरिएंट**: `cpci`
- **डिफ़ॉल्ट पोर्ट**: 0 (मेमोरी-मैप्ड बस)
- **ट्रांसपोर्ट**: sysfs `/sys/bus/pci/devices/<BDF>/config`

CompactPCI (PICMG 2.0) पारंपरिक PCI के समान विद्युत और सॉफ्टवेयर इंटरफ़ेस
का उपयोग करता है। कोडेक एप्लिकेशन और PCI कॉन्फ़िगरेशन स्पेस के बीच sysfs के
माध्यम से कच्चे बाइट्स को पारित करता है।

## कर्नेल आवश्यकताएँ

निम्नलिखित कर्नेल मॉड्यूल लोड होने चाहिए:

- `pcieport` -- PCI Express पोर्ट ड्राइवर (हाइब्रिड CPCIe सिस्टम के लिए)
- `pci_sysfs` -- sysfs PCI इंटरफ़ेस (अधिकांश कर्नेल में निर्मित)
- `cpci_hotplug` -- CompactPCI हॉटप्लग कंट्रोलर (वैकल्पिक, हॉट-स्वैप के लिए)

sysfs फाइलसिस्टम `/sys` पर माउंट होना चाहिए। यह सभी आधुनिक Linux
वितरणों पर डिफ़ॉल्ट है।

आवश्यक अनुमतियाँ:
- कॉन्फ़िगरेशन स्पेस एक्सेस के लिए रूट एक्सेस या `CAP_SYS_ADMIN`
- कॉन्फ़िगरेशन फ़ाइल root:root के स्वामित्व में mode 0600 के साथ

## ड्राइवर

```go
d, err := cpci.NewCPCIDriver("0000:02:00.0")
if err != nil {
    log.Fatal(err)
}
defer d.Close()

tr := d.Transport()
// Use tr.Read/tr.Write for raw CPCI config space access
```

## CompactPCI बनाम PCI

CompactPCI मानक PCI बस एन्यूमरेशन और कॉन्फ़िगरेशन स्पेस का उपयोग करता है।
डेस्कटॉप PCI से मुख्य अंतर:

- **3U/6U फॉर्म फैक्टर**: पिन-एंड-सॉकेट कनेक्टर के साथ यूरोकार्ड मैकेनिक्स
- **बस नंबरिंग**: प्रत्येक CPCI चेसिस सेगमेंट को अपना PCI बस नंबर मिलता है
- **हॉट स्वैप**: PICMG 2.1 हॉट स्वैप मानक PCI हॉटप्लग मॉडल का उपयोग करता है
- **सिस्टम स्लॉट**: बस 0, डिवाइस 0 सिस्टम स्लॉट कंट्रोलर है

## BDF फॉर्मेट

बस पता एक BDF (Bus:Device.Function) स्ट्रिंग है:
- `0000:02:00.0` -- domain 0000, bus 02, device 00, function 0
- `0000:02:08.0` -- domain 0000, bus 02, device 08, function 0
