# SDK بروتوكول PCI / PCIe

ينفّذ `kernel.Protocol` للوصول إلى ناقل PCI و PCI Express عبر sysfs في Linux.

## البروتوكول

- **الاسم**: `pci`
- **الأنواع (Variants)**: `pci`
- **المنفذ الافتراضي**: 0 (ناقل معرف بالذاكرة)
- **النقل**: sysfs `/sys/bus/pci/devices/<BDF>/config`

يمرر المرمّز البايتات الخام بين التطبيق ومساحة إعداد PCI.
تذهب القراءات والكتابات مباشرة إلى سجلات إعداد الجهاز
عبر ملف الإعداد في sysfs.

## متطلبات النواة

يجب تحميل وحدات النواة التالية:

- `pcieport` -- برنامج تشغيل منفذ PCI Express
- `pci_sysfs` -- واجهة PCI عبر sysfs (مدمجة في معظم النوى)

يجب أن يكون نظام الملفات sysfs مركبًا عند `/sys`. وهذا هو الافتراضي
في جميع توزيعات Linux الحديثة.

الصلاحيات المطلوبة:
- وصول الجذر أو `CAP_SYS_ADMIN` للوصول إلى مساحة الإعداد
- ملف الإعداد مملوك لـ root:root بوضع 0600

## برنامج التشغيل

```go
d, err := pci.NewPCIDriver("0000:00:1f.3")
if err != nil {
    log.Fatal(err)
}
defer d.Close()

tr := d.Transport()
// Use tr.Read/tr.Write for raw PCI config space access
```

## تنسيق BDF

عنوان الناقل هو سلسلة BDF (الناقل:الجهاز.الوظيفة):
- `0000:00:1f.3` -- المجال 0000، الناقل 00، الجهاز 1f، الوظيفة 3
- `0000:01:00.0` -- المجال 0000، الناقل 01، الجهاز 00، الوظيفة 0
