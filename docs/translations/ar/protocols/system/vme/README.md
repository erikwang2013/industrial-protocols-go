# SDK بروتوكول VME / VPX

ينفّذ `kernel.Protocol` للوصول إلى ناقل VMEbus و VPX عبر procfs في Linux.

## البروتوكول

- **الاسم**: `vme`
- **الأنواع (Variants)**: `vme`
- **المنفذ الافتراضي**: 0 (ناقل معرف بالذاكرة)
- **النقل**: procfs `/proc/vme/<slot>`

يمرر المرمّز البايتات الخام بين التطبيق ومساحة عناوين VME.
تذهب القراءات والكتابات مباشرة إلى الناقل عبر واجهة procfs
التي يوفرها برنامج تشغيل نواة VME.

## متطلبات النواة

يجب تحميل وحدة النواة التالية:

- `vme_tsi148` -- برنامج تشغيل جسر VME من Tundra TSI148 (الأكثر شيوعًا)
  - مدعوم أيضًا: `vme_ca91cx42` (Universe II)، `vme_user`

يجب أن يكون نظام الملفات procfs مركبًا عند `/proc`.

الصلاحيات المطلوبة:
- وصول الجذر مطلوب لفتح `/proc/vme/<slot>` للقراءة والكتابة
- عُقد الأجهزة مملوكة لـ root:root

## برنامج التشغيل

```go
d, err := vme.NewVMEDriver(0) // slot 0
if err != nil {
    log.Fatal(err)
}
defer d.Close()

tr := d.Transport()
// Use tr.Read/tr.Write for raw VME bus access
```

## أوضاع عنونة VME

يمرر المرمّز جميع بايتات معدّل العنوان والعنوان بشفافية.
يجب على التطبيقات إلحاق معلومات العنونة بحمولة البيانات:

- **A16**: مساحة عناوين I/O قصيرة 16-bit
- **A24**: مساحة عناوين قياسية 24-bit
- **A32**: مساحة عناوين موسعة 32-bit

## توافق VPX

يمكن لأنظمة VPX (VITA 46) التي تعرض واجهة procfs متوافقة مع VME
استخدام هذا البرنامج. ترقيم الفتحات هو نفسه.
