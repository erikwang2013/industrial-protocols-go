# SDK جسر بوابة LonWorks

بروتوكول LonWorks (ANSI/CEA-709.1) عبر جسر بوابة TCP.

## الأجهزة

| البوابة | الواجهة | IP الافتراضي |
|---------|-----------|-------------|
| Echelon U60 | واجهة شبكة FT-10 عبر USB | يحدده المضيف |
| Echelon U70 | واجهة TP/XF-1250 عبر USB | يحدده المضيف |
| Loytec L-IP | موجه LonWorks/IP | 192.168.0.90 |

## التوصيلات

- FT-10 (طوبولوجيا حرة): زوج مجدول غير حساس للقطبية، حتى 500 متر بطوبولوجيا حرة
- TP/XF-1250: طوبولوجيا ناقل مع إنهاء 105 أوم
- إيثرنت على موجه L-IP لجسر TCP

## إعداد IP البوابة

```go
driver, codec, err := lonworks.NewGatewayDriver("192.168.0.90:2009")
handler, err := lonworks.ReadyHandler("192.168.0.90:2009")
```
