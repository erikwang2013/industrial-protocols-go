# SDK протокола PCI / PCIe

Реализует `kernel.Protocol` для доступа к шинам PCI и PCI Express через sysfs Linux.

## Протокол

- **Имя**: `pci`
- **Варианты**: `pci`
- **Порт по умолчанию**: 0 (шина с отображаемой в память адресацией)
- **Транспорт**: sysfs `/sys/bus/pci/devices/<BDF>/config`

Кодек прозрачно передаёт сырые байты между приложением и конфигурационным
пространством PCI. Чтения и записи идут напрямую в регистры конфигурации
устройства через файл конфигурации sysfs.

## Требования к ядру

Должны быть загружены следующие модули ядра:

- `pcieport` — драйвер порта PCI Express
- `pci_sysfs` — интерфейс PCI в sysfs (встроен в большинство ядер)

Файловая система sysfs должна быть смонтирована в `/sys`. Это поведение
по умолчанию во всех современных дистрибутивах Linux.

Требуемые права:
- Доступ root или `CAP_SYS_ADMIN` для доступа к конфигурационному пространству
- Файл конфигурации принадлежит root:root с правами 0600

## Драйвер

```go
d, err := pci.NewPCIDriver("0000:00:1f.3")
if err != nil {
    log.Fatal(err)
}
defer d.Close()

tr := d.Transport()
// Используйте tr.Read/tr.Write для прямого доступа к конфигурационному пространству PCI
```

## Формат BDF

Адрес шины — строка BDF (Bus:Device.Function):
- `0000:00:1f.3` — домен 0000, шина 00, устройство 1f, функция 3
- `0000:01:00.0` — домен 0000, шина 01, устройство 00, функция 0
