# SDK протокола SAE J1850 CAN

SAE J1850 — стандарт автомобильной связи, используемый для бортовой диагностики (OBD-II). Этот пакет предоставляет кодек J1850 поверх шины CAN (ISO 15765-4 / CAN TP).

## Обзор протокола

SAE J1850 OBD-II поверх CAN использует 29-битные расширенные идентификаторы CAN со следующей структурой:

### Формат CAN ID (29 бит)

| Биты       | Поле    | Описание                        |
|-----------|----------|------------------------------------|
| 28-26     | Priority | Приоритет сообщения (0-7, по умолчанию 6) |
| 25        | Ext ID   | Всегда 1 для расширенных кадров    |
| 24-16     | PF       | Формат параметра (заголовок)      |
| 15-8      | PS       | Специфические параметры (цель/источник) |
| 7-0       | SA       | Адрес источника                   |

### Стандартные CAN ID OBD-II

| Тип                | CAN ID (hex)    | Описание                    |
|--------------------|-----------------|--------------------------------|
| Физический запрос   | 0x18DAxxF1      | Запрос к конкретному ECU (xx=адрес) |
| Физический ответ    | 0x18DAF1xx      | Ответ от ECU (xx=адрес)      |
| Функциональный запрос | 0x18DB33F1      | Широковещательная передача всем ECU |

### Формат кадра ISO 15765-2

Одиночный кадр: старший полубайт байта 0 = длина данных (0-7), младший полубайт + остальные байты = диагностические данные.

## Требования к аппаратуре

- **Linux** с поддержкой SocketCAN
- Адаптер J1850-CAN OBD-II (например, совместимый с ELM327 USB-to-CAN, OBDLink SX, Macchina M2)
- Автомобиль с разъёмом OBD-II (большинство автомобилей 1996 г. и новее)

### Настройка интерфейса CAN

```bash
sudo modprobe can
sudo modprobe can_raw
sudo ip link set can0 type can bitrate 500000
sudo ip link set up can0
```

## Использование

```go
package main

import (
    "github.com/erikwang2013/industrial-protocols-go/kernel"
    "github.com/erikwang2013/industrial-protocols-go/protocols/automotive/saej1850"
)

func main() {
    p := saej1850.New()
    codec, _ := p.NewCodec("can")

    // Mode $01 PID $0C: обороты двигателя
    req := &kernel.Request{
        Function: "mode01",
        Metadata: map[string]any{"pid": float64(0x0C)},
    }
    raw, _ := codec.Encode(req)
    _ = raw

    // Mode $03: запрос DTC, связанных с выбросами
    req2 := &kernel.Request{Function: "mode03"}
    raw2, _ := codec.Encode(req2)
    _ = raw2
}
```

## Поддерживаемые функции

| Функция        | Режим OBD-II | Описание                         |
|----------------|-------------|-------------------------------------|
| `mode01`       | $01         | Запрос текущих данных силовой установки |
| `mode03`       | $03         | Запрос DTC, связанных с выбросами |
| `mode0A`       | $0A         | Запрос постоянных DTC             |
| `diag_request` | Свой        | Общий диагностический запрос      |
| `diag_response`| -           | Кадр диагностического ответа      |
| `broadcast`    | -           | Функциональная широковещательная передача всем ECU |
