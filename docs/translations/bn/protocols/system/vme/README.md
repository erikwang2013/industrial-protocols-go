# VME / VPX প্রোটোকল SDK

Linux procfs-এর মাধ্যমে VMEbus ও VPX বাস অ্যাক্সেসের জন্য `kernel.Protocol` বাস্তবায়ন করে।

## প্রোটোকল

- **নাম**: `vme`
- **ভ্যারিয়েন্ট**: `vme`
- **ডিফল্ট পোর্ট**: 0 (মেমরি-ম্যাপড বাস)
- **ট্রান্সপোর্ট**: procfs `/proc/vme/<slot>`

কোডেকটি অ্যাপ্লিকেশন এবং VME অ্যাড্রেস স্পেসের মধ্যে র-বাইট পাস-থ্রু করে। VME কার্নেল ড্রাইভার কর্তৃক প্রদত্ত procfs ইন্টারফেসের মাধ্যমে পড়া ও লেখা সরাসরি বাসে যায়।

## কার্নেল প্রয়োজনীয়তা

নিম্নলিখিত কার্নেল মডিউলটি লোড করা আবশ্যক:

- `vme_tsi148` -- Tundra TSI148 VME ব্রিজ ড্রাইভার (সবচেয়ে প্রচলিত)
  - সমর্থিতও: `vme_ca91cx42` (Universe II), `vme_user`

procfs ফাইলসিস্টেম অবশ্যই `/proc`-এ মাউন্ট করা থাকতে হবে।

প্রয়োজনীয় অনুমতি:
- read-write-এর জন্য `/proc/vme/<slot>` খুলতে রুট অ্যাক্সেস প্রয়োজন
- ডিভাইস নোডগুলো root:root মালিকানাধীন

## ড্রাইভার

```go
d, err := vme.NewVMEDriver(0) // slot 0
if err != nil {
    log.Fatal(err)
}
defer d.Close()

tr := d.Transport()
// Use tr.Read/tr.Write for raw VME bus access
```

## VME অ্যাড্রেসিং মোড

কোডেকটি সব অ্যাড্রেস মডিফায়ার ও অ্যাড্রেস বাইট স্বচ্ছভাবে পাস-থ্রু করে। অ্যাপ্লিকেশনগুলোর ডেটা পেলোডের আগে অ্যাড্রেসিং তথ্য যুক্ত করা উচিত:

- **A16**: 16-বিট শর্ট I/O অ্যাড্রেস স্পেস
- **A24**: 24-বিট স্ট্যান্ডার্ড অ্যাড্রেস স্পেস
- **A32**: 32-বিট এক্সটেন্ডেড অ্যাড্রেস স্পেস

## VPX সামঞ্জস্য

VME-সামঞ্জস্যপূর্ণ procfs ইন্টারফেস প্রদানকারী VPX (VITA 46) সিস্টেমগুলো এই ড্রাইভার ব্যবহার করতে পারে। স্লট নম্বরিং একই।
