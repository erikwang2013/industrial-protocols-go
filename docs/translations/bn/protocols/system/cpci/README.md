# CompactPCI প্রোটোকল SDK

Linux sysfs-এর মাধ্যমে CompactPCI বাস অ্যাক্সেসের জন্য `kernel.Protocol` বাস্তবায়ন করে।

## প্রোটোকল

- **নাম**: `cpci`
- **ভ্যারিয়েন্ট**: `cpci`
- **ডিফল্ট পোর্ট**: 0 (মেমরি-ম্যাপড বাস)
- **ট্রান্সপোর্ট**: sysfs `/sys/bus/pci/devices/<BDF>/config`

CompactPCI (PICMG 2.0) প্রচলিত PCI-এর মতোই একই ইলেকট্রিক্যাল ও সফটওয়্যার ইন্টারফেস ব্যবহার করে। কোডেকটি sysfs-এর মাধ্যমে অ্যাপ্লিকেশন এবং PCI কনফিগ স্পেসের মধ্যে র-বাইট পাস-থ্রু করে।

## কার্নেল প্রয়োজনীয়তা

নিম্নলিখিত কার্নেল মডিউলগুলো লোড করা আবশ্যক:

- `pcieport` -- PCI Express পোর্ট ড্রাইভার (হাইব্রিড CPCIe সিস্টেমের জন্য)
- `pci_sysfs` -- sysfs PCI ইন্টারফেস (অধিকাংশ কার্নেলে বিল্ট-ইন)
- `cpci_hotplug` -- CompactPCI হটপ্লাগ কন্ট্রোলার (ঐচ্ছিক, হট-সোয়াপের জন্য)

sysfs ফাইলসিস্টেম অবশ্যই `/sys`-এ মাউন্ট করা থাকতে হবে। এটি সব আধুনিক Linux ডিস্ট্রিবিউশনে ডিফল্ট।

প্রয়োজনীয় অনুমতি:
- কনফিগ স্পেস অ্যাক্সেসের জন্য রুট অ্যাক্সেস বা `CAP_SYS_ADMIN`
- কনফিগ ফাইলটি root:root মালিকানাধীন, মোড 0600

## ড্রাইভার

```go
d, err := cpci.NewCPCIDriver("0000:02:00.0")
if err != nil {
    log.Fatal(err)
}
defer d.Close()

tr := d.Transport()
// Use tr.Read/tr.Write for raw CPCI config space access
```

## CompactPCI বনাম PCI

CompactPCI স্ট্যান্ডার্ড PCI বাস এনুমারেশন ও কনফিগ স্পেস ব্যবহার করে। ডেস্কটপ PCI থেকে মূল পার্থক্য:

- **3U/6U ফর্ম ফ্যাক্টর**: পিন-অ্যান্ড-সকেট কানেক্টরসহ ইউরোকার্ড মেকানিক্স
- **বাস নম্বরিং**: প্রতিটি CPCI চেসিস সেগমেন্ট নিজস্ব PCI বাস নম্বর পায়
- **হট সোয়াপ**: PICMG 2.1 হট সোয়াপ স্ট্যান্ডার্ড PCI হটপ্লাগ মডেল ব্যবহার করে
- **সিস্টেম স্লট**: বাস 0, ডিভাইস 0 হল সিস্টেম স্লট কন্ট্রোলার

## BDF ফরম্যাট

বাস অ্যাড্রেস একটি BDF (Bus:Device.Function) স্ট্রিং:
- `0000:02:00.0` -- ডোমেইন 0000, বাস 02, ডিভাইস 00, ফাংশন 0
- `0000:02:08.0` -- ডোমেইন 0000, বাস 02, ডিভাইস 08, ফাংশন 0
