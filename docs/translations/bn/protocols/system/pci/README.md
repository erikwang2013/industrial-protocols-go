# PCI / PCIe প্রোটোকল SDK

Linux sysfs-এর মাধ্যমে PCI ও PCI Express বাস অ্যাক্সেসের জন্য `kernel.Protocol` বাস্তবায়ন করে।

## প্রোটোকল

- **নাম**: `pci`
- **ভ্যারিয়েন্ট**: `pci`
- **ডিফল্ট পোর্ট**: 0 (মেমরি-ম্যাপড বাস)
- **ট্রান্সপোর্ট**: sysfs `/sys/bus/pci/devices/<BDF>/config`

কোডেকটি অ্যাপ্লিকেশন এবং PCI কনফিগ স্পেসের মধ্যে র-বাইট পাস-থ্রু করে। sysfs কনফিগ ফাইলের মাধ্যমে পড়া ও লেখা সরাসরি ডিভাইসের কনফিগারেশন রেজিস্টারে যায়।

## কার্নেল প্রয়োজনীয়তা

নিম্নলিখিত কার্নেল মডিউলগুলো লোড করা আবশ্যক:

- `pcieport` -- PCI Express পোর্ট ড্রাইভার
- `pci_sysfs` -- sysfs PCI ইন্টারফেস (অধিকাংশ কার্নেলে বিল্ট-ইন)

sysfs ফাইলসিস্টেম অবশ্যই `/sys`-এ মাউন্ট করা থাকতে হবে। এটি সব আধুনিক Linux ডিস্ট্রিবিউশনে ডিফল্ট।

প্রয়োজনীয় অনুমতি:
- কনফিগ স্পেস অ্যাক্সেসের জন্য রুট অ্যাক্সেস বা `CAP_SYS_ADMIN`
- কনফিগ ফাইলটি root:root মালিকানাধীন, মোড 0600

## ড্রাইভার

```go
d, err := pci.NewPCIDriver("0000:00:1f.3")
if err != nil {
    log.Fatal(err)
}
defer d.Close()

tr := d.Transport()
// Use tr.Read/tr.Write for raw PCI config space access
```

## BDF ফরম্যাট

বাস অ্যাড্রেস একটি BDF (Bus:Device.Function) স্ট্রিং:
- `0000:00:1f.3` -- ডোমেইন 0000, বাস 00, ডিভাইস 1f, ফাংশন 3
- `0000:01:00.0` -- ডোমেইন 0000, বাস 01, ডিভাইস 00, ফাংশন 0
