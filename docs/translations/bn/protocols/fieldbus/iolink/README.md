# IO-Link GatewayBridge SDK

TCP গেটওয়ে ব্রিজের মাধ্যমে IO-Link প্রোটোকল।

## হার্ডওয়্যার

| গেটওয়ে | ইন্টারফেস | ডিফল্ট IP |
|---------|-----------|-------------|
| ifm AL1332 | IO-Link মাস্টার (EtherNet/IP) | 192.168.0.40 |
| Balluff BNI00AZ | IO-Link মাস্টার (PROFINET) | 192.168.0.41 |
| SICK SIG200 | IO-Link মাস্টার (ইথারনেট) | 192.168.0.42 |

## ওয়্যারিং

- প্রতিটি IO-Link পোর্টের জন্য M12 কানেক্টর (4-পিন): L+ (বাদামি), L- (নীল), C/Q (কালো), অব্যবহৃত (সাদা)
- মাস্টার ও ডিভাইসের জন্য 24 VDC পাওয়ার সাপ্লাই
- TCP ব্রিজের জন্য মাস্টারে ইথারনেট

## গেটওয়ে IP কনফিগারেশন

```go
driver, codec, err := iolink.NewGatewayDriver("192.168.0.40:2004")
handler, err := iolink.ReadyHandler("192.168.0.40:2004")
```
