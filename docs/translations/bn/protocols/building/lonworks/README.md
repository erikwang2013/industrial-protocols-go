# LonWorks GatewayBridge SDK

TCP গেটওয়ে ব্রিজের মাধ্যমে LonWorks (ANSI/CEA-709.1) প্রোটোকল।

## হার্ডওয়্যার

| গেটওয়ে | ইন্টারফেস | ডিফল্ট IP |
|---------|-----------|-------------|
| Echelon U60 | USB FT-10 নেটওয়ার্ক ইন্টারফেস | হোস্ট-নির্ধারিত |
| Echelon U70 | USB TP/XF-1250 ইন্টারফেস | হোস্ট-নির্ধারিত |
| Loytec L-IP | LonWorks/IP রাউটার | 192.168.0.90 |

## ওয়্যারিং

- FT-10 (ফ্রি টপোলজি): পোলারিটি-ইনসেন্সিটিভ টুইস্টেড পেয়ার, ৫০০ মিটার পর্যন্ত ফ্রি টপোলজি
- TP/XF-1250: ১০৫ ওহম টার্মিনেটরসহ বাস টপোলজি
- TCP ব্রিজের জন্য L-IP রাউটারে ইথারনেট

## গেটওয়ে IP কনফিগারেশন

```go
driver, codec, err := lonworks.NewGatewayDriver("192.168.0.90:2009")
handler, err := lonworks.ReadyHandler("192.168.0.90:2009")
```
